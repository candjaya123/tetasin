# Tetasin — Design System & UI Direction

## Brand Overview

**Tetasin** adalah platform POS dan manajemen bisnis modern untuk UMKM Indonesia.

Fokus utama:

* membantu bisnis lebih tertata
* mempermudah operasional harian
* membuat pengelolaan usaha terasa modern namun tetap sederhana

# UX Principles

## Tetasin UX Philosophy

### 1. Simple First

Semua fitur harus mudah dipahami bahkan untuk user non-teknis.

### 2. Fast Interaction

Aksi penting maksimal 1–2 klik.

### 3. Clean Information

Jangan tampilkan terlalu banyak data sekaligus.

### 4. Mobile Priority

Karena mayoritas UMKM akan memakai mobile.

### 5. Friendly Finance

Keuangan harus terasa mudah, bukan menakutkan.

---

# Final Direction

Tetasin harus terasa seperti:

> aplikasi bisnis modern yang membantu UMKM Indonesia menjadi lebih rapi, cepat, dan berkembang.
